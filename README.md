# WPP Marketing API

Official API documentation for the WPP Marketing WhatsApp automation platform.

## Documentation

Access the interactive Swagger documentation for the Messaging API and Events API:

https://api.wppmarketing.com/docs/

## Features

- Send WhatsApp text messages
- Send images, documents and other media
- Retrieve sent message logs and delivery status
- Retrieve webhook delivery logs
- Receive cart, order, payment, shipping, cancellation and customer events
- Trigger automated WhatsApp interactions from e-commerce, ERP and custom systems

## Authentication

The APIs use Bearer Token authentication.

Base URL:

https://api.wppmarketing.com
